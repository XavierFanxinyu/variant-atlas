PVS1

功能丧失（LOF）机制的无功能变异

自动化Very Strong§5.1
⚡ 怎么用 · 速判
  1. 前提：基因-疾病机制为 LOF，关联强度 STRONG / DEFINITIVE，且 ≥3 个 LOF 变异致病、>10% 表型相关变异为 LOF（跨 1 个以上外显子）。
  2. 定级：按图 1 决策树走「是否预测 NMD → 外显子是否存在于生物学相关转录本 → 区域功能是否已知 / 截短区是否关键 → 变异去除蛋白 >10% 或 <10%」。
  3. 降级：关联 Moderate 且「≥2 个 LOF 变异 + 动物模型可重复表型」→ 降 1 级；两者只满足其一 → 降 2 级。
  4. 禁用：无 LOF 致病证据、机制非 LOF、与 PP3 剪接预测联合使用。
输出：PVS1（Very Strong）/ PVS1_Strong / PVS1_Moderate / PVS1_Supporting / N/A；自动化结果需人工复核基因是否为 LOF 机制。
5.1.1 ACMG-2015 Guideline

当一个疾病的致病机制为功能丧失（LOF）时的无功能变异（无义突变、移码突变、经典 ±1 或 2 的剪接突变、起始密码子变异、单个或多个外显子缺失）[1]。

适用变异类型：null 变异，包括 splice-3、splice-5、start-loss、alt-start、frameshift、nonsense、stop-gain、span 以及 RNA 剪接实验结果导致异常剪接的变异[1,24]。

5.1.2 解读规则

ClinGen 的序列变异解释工作组提出了决策树来解决 PVS1 解释过程中的变异特定问题，按决策路径分配初步的 PVS1 强度级别[9]。结合近年 ClinGen 专家小组更新的补充建议[24]以及 ACGS（英国临床基因组科学协会）变异分级实践指南[23]，调整后的 PVS1 证据使用规则见图 1。

5.1.3 注意事项 · 变异是否符合 LOF 机制
  1. 变异关联疾病符合 PVS1 使用前提：a. 基因和疾病的关联强度是 STRONG 或 DEFINITIVE 以及 b. ≥3 个 LOF 变异是致病性的（变异不通过 PVS1 即可达到致病等级）并且 >10% 与表型相关的变异是 LOF（必须跨越 1 个以上的外显子）。
  2. 最终强度降低 1 级（Very Strong → Strong）：a. 基因-疾病关联强度是 Moderate；b. ≥2 个 LOF 变异与表型相关（必须跨越 1 个以上外显子）以及动物模型实验可以重复疾病表型。
  3. 最终强度降低 2 级（Very Strong → Moderate）：a. 基因-疾病关联强度是 Moderate；b. ≥2 个 LOF 变异与表型相关（必须跨越 1 个以上外显子）或者动物模型实验可以重复疾病表型。
  4. 如果没有证据表明 LOF 变异导致疾病，无论是否为烈性突变都不可用 PVS1。
5.1.4 人工校正

对于自动化输出有 PVS1 相关证据的基因变异，注意核对该基因是否是 LOF 机制；若基因关联疾病的致病机制不是 LOF 机制，则不能使用 PVS1 相关证据。

PS1

与已知致病变异相同的氨基酸改变 / 剪接预测效果

自动化Strong§5.2
⚡ 怎么用 · 速判
  1. 前提：同一位点已有已知致病（P）或疑似致病（LP）变异。
  2. 相同氨基酸 / 核苷酸改变 → 表 1：已知 P = 4 分/例，已知 LP = 2 分/例（含起始密码子变异、非编码 RNA 变异）。
  3. 相同剪接预测效果 → 表 2：按 VUA 位置、预测证据（PP3 或 PVS1 及其强度）、已知变异为 P / LP 查对应等级。
  4. 累计：4 分 → PS1；2 分 → PS1_Moderate。
输出：PS1（Strong）/ PS1_Moderate / PS1_Supporting / N/A。
5.2.1 ACMG-2015 Guideline

与已确定的致病/疑似致病变异具有相同的氨基酸改变，或剪接供/受体基序内的变异（影响剪接）具有相同的剪接预测效果[1,24]。

适用变异类型：错义变异（注意剪切影响的改变）、起始密码子变异、剪接供体基序（外显子的最后 3 个碱基和内含子的前 6 个碱基）变异、剪接受体变异（外显子的第 1 个碱基和内含子的最后 20 个碱基）变异、非编码 RNA 基因变异。

PS2/PM6

新发（de novo）变异

人工§5.3
⚡ 怎么用 · 速判
  1. 前提：变异为 de novo。
  2. 逐例先证者：① 判断表型与基因一致性（4 档）② 是否经生物学父母验证（WES-trio 亦可）——验证走 PS2，未验证走 PM6 ③ 按表 3 打分（2 / 1 / 0.5 / 0.25 / 0）。
  3. 累加：核查其他先证者后，按表 4 的累计分值定级。
0.5 / 1 / 2 / 4 分 → Supporting / Moderate（含 PM6）/ Strong / VeryStrong。
5.3.1 ACMG-2015 Guideline

PS2：患者的新发变异，且无家族史（经双亲验证）[1]。
PM6：未经父母样本验证的新发变异[1]。

PS3/BS3

功能实验证据（含良性方向 BS3）

人工§5.4
⚡ 怎么用 · 速判
  1. 前提：功能实验与疾病发病机制及表型相关（LOF / GOF）。
  2. 有 Odds Path 值 → 表 5：<0.053 / <0.23 / <0.48 → BS3 / BS3_M / BS3_S；0.48–2.1 → Indeterminate；>2.1 / >4.3 / >18.7 / >350 → PS3_S / PS3_M / PS3 / PS3_VeryStrong。
  3. 无 Odds 值 → 表 6：酶活影响 >50%（<50%）、≥11 项（≤10 项）验证对照、哺乳动物（非哺乳动物）knock-in 模型、方法学成熟度。
致病方向输出 PS3 系列，良性方向输出 BS3 系列；具体实验类型见表 7。
5.4.1 ACMG-2015 Guideline

PS3：体内、体外功能实验已明确会导致基因功能受损的变异[1]。
BS3：在体内外实验中确认对蛋白质功能和剪接没有影响的变异[1]。

5.4.2 解读规则

文献有功能实验表明对基因或产物有损害，适用 PS3；反之适用 BS3。在功能实验与疾病发病机制及其表型相关的前提下（如 LOF、GOF）[17]，功能证据包括但不限于：

  1. 产物浓度降低或产物活性降低；
  2. 动物实验表明与野生型存在有害差异；
  3. 剪切实验的 mRNA 产物验证，如取材自患者的 mRNA 分析或 minigene 剪切分析；
  4. 针对特定变异的体外功能实验，如针对转录因子的报告基因分析或针对错义变异的饱和基因组编辑（saturation genome editing）[16]。

5）证据强度判定：① 通过文献获得 Odds 值参照表 5确定 PS3/BS3 强度；② 若无法获得 Odds 值参照表 6确定强度。

OddsPath = [P2 × (1−P1)] / [(1−P2) × P1]

PS4

病例组频率显著高于对照组 / 先证者计数

人工§5.5
⚡ 怎么用 · 速判
  1. 路径 A · case-control：研究患者群组 ≥10 人，OR > 5 且 95%CI 不含 1 → PS4；control 未检出变异时四格表 4 个数值各 +0.5。
  2. 路径 B · 先证者计数：AD / XL 疾病，无 case-control 或 OR 不达标，且满足 PM2_supporting 时，≥15 / ≥6 / ≥2 例 → PS4 / PS4_M / PS4_P。
  3. 禁用：control 未检测该变异、不同地域人群数据相加、同一先证者重复计数、先证者表型不符。
输出：PS4（Strong）/ PS4_M / PS4_P；高频致病变异的频率前提可特殊处理。
5.5.1 ACMG-2015 Guideline

变异出现在患病群体中的频率显著高于对照群体[1]。

5.5.2 解读规则
  • 5.5.2.1 case-control 路径：文献中有 case-control 研究结果、case 和 control 人群的总数与变异检出数明确、且研究患者群组的总人数 ≥10 个，此时计算 OR 值进行判定；OR 值 > 5 且 95% 置信区间不包括 1，则适用 PS4。
  • 5.5.2.2 先证者计数路径：待解读变异关联 AD / XL 疾病，文献中无 case-control 研究或 OR 值不满足上述标准，但在多例具有相同表型的先证者中检出时，可使用先证者个数评估。在待解读变异满足 PM2_supporting 的情况下：≥15 例先证者为 PS4、≥6 例为 PS4_M、≥2 例为 PS4_P[3]。
5.5.3 注意事项
  1. 计算 OR 值时，若 control 人群中未检出携带待解读变异，则计算 OR 值用的 4 个数值均加 0.5 后再计算[13,14]。OR 值计算网页：http://www.hutchon.net/ConfidOR.htm；https://www.medcalc.org/calc/odds_ratio.php
  2. 先证者需满足相关表型要求。
  3. 使用 case-control 研究结果时，需注意地域人群对应（不同文献中的 case 和 control 集不要相加使用）。
  4. 需注意核查文献中是否在 control 中检测了待解读变异；如 control 仅用于验证生化指标、个别变异（非待解读变异），则不适用计算 OR 值。
  5. 若不同先证者表型对应基因关联的不同疾病，且基因的致病机理一致，则可合并使用（如 COL4A4）。
  6. 若不同文献中有相同的先证者，不能重复计算。
  7. 通常情况下，按照先证者个数评估 PS4 时要求待解读变异频率满足 PM2_supporting；但当变异为明确的高频致病变异时，可特殊处理。
PM1

热点突变区域 / 关键功能域

自动化Moderate§5.6
⚡ 怎么用 · 速判
  1. 适用：错义 / 框内插入缺失，位于无良性变异的关键功能域，或多个相邻氨基酸存在较高频率已知致病变异的热点区。
  2. 量化：gnomAD MCR missense OE —— 0 < OE ≤ 0.2112 → PM1；0.2112 < OE ≤ 0.3747 → PM1_Supporting。
  3. 冲突：与 PP3 共用时最高 Strong；与 PP2 同时满足时保留 PM1。
输出：PM1（Moderate）/ PM1_Supporting。
5.6.1 ACMG-2015 Guideline

位于热点突变区域，和/或位于已知无良性变异的关键功能域[1]。
适用类型：missense、cds-ins、cds-del、cds-indel。

5.6.2 解读规则

蛋白关键结构域没有已知良性变异、发现的错义变异均被证实为致病变异，则位于关键结构域的错义或整码变异可使用 PM1。基因中尚未确定的功能区域存在多个致病变异，若发生在变异热点区域上，且一个或多个相邻氨基酸中存在较高频率的已知致病变异，也可使用 PM1。

可参考 gnomAD 中 MCR missense OE 参数：当 0 < OE ≤ 0.2112 时使用 PM1；当 0.2112 < OE ≤ 0.3747 时使用 PM1_Supporting[21]。

5.6.3 注意事项
本节编号存在笔误（印为 5.7.3.1 / 5.7.3.2，应为 5.6.3），此处按内容顺序收录。
  • PM1 与 PP3 共用时，最高等级为 Strong。
  • PM1 与 PP2 同时满足时，保留 PM1；PM1_Supporting 与 PP2 同时满足时，保留其中一个。

自动化Supporting（降级后）§5.7
⚡ 怎么用 · 速判
  1. 先查覆盖度：低覆盖率区域、复杂 indel / 重复扩展等不易被 NGS 识别的变异不适用。
  2. 仅 AD：任一数据库总人频为 0 / 无频率（外显不全阈值 0.00001）。
  3. 含 AR / XL / 未明确：总人频或样本对应人种频率 ≤ 0.5% / 无频率。

5.7.1 ACMG-2015 Guideline

ESP6500、1000G 或 ExAC 数据库中正常对照人群中未发现的变异（或隐性遗传病种极低频位点）。

5.7.2 解读规则
  1. ESP、ExAC、GnomAD、GnomAD[East Asian] 等数据库正常对照人群频率收录为低频甚至未收录，适用 PM2 证据项。
  2. 若基因关联疾病遗传模式仅 AD，则要求 ESP6500/1000G/gnomAD 任何一个数据库中总人频均为 0 或无频率（特殊疾病/基因除外），外显不全的阈值是 0.00001。
  3. 若基因关联的疾病遗传模式含 AR/XL 或未明确，则要求 ESP6500/1000G/GnomAD/GnomAD[East Asian] 任何一个数据库中总人频、或者以及和样本相关的 ESP6500/1000G/GnomAD/GnomAD[East Asian] 人种频率均 ≤0.5% 或无频率。

⚡ 怎么用 · 速判

人工§5.14
⚡ 怎么用 · 速判

  2. 满足其一即可：文献中患者疾病与基因对应疾病完全一致；医生明确或疑似诊断的疾病与基因对应疾病完全一致；高度特异疾病存在多种亚型、文献或诊断未具体到亚型（如 IDUA 与粘多糖贮积症 1h / 1h/s / 1s）。

变异携带者的表型或家族史高度符合某种单基因遗传疾病[1]。

5.14.2 解读规则

在家族史与疾病遗传方式一致的前提下，符合以下情况之一者可得分：

  1. 5.14.2.1 文献中的患者所患疾病与基因对应疾病完全一致；
  2. 5.14.2.2 医生明确或疑似诊断的疾病与基因对应疾病完全一致；
  3. 5.14.2.3 与基因高度特异的疾病，若有多种亚型，文献患者或临床医生明确/疑似诊断的疾病未具体到亚型的，可加分；如 IDUA 基因关联粘多糖贮积症 1h、1h/s 和 1s 型，若文献中患者为粘多糖贮积症，PP4 可加分。

健康成年人中检出（早期完全外显疾病）

自动化§5.16
⚡ 怎么用 · 速判
  1. 前提：早期完全外显的疾病；晚发或不完全外显基因不建议使用。

对于早期完全外显的疾病，在健康成年人中发现该变异（隐性遗传病发现纯合、显性遗传病发现杂合，或者 X 连锁合子）[1]。

5.16.2 解读规则

对于早期完全外显的疾病：AD 遗传模式杂合子、AR 遗传模式纯合子和 XL 遗传模式的半合子数记录 ≥5 个时，可用 BS2。晚发或不完全外显基因不建议使用 BS2。

5.16.3 注意事项

注意疾病遗传方式（AD–杂合子；AR–纯合子；X 连锁–半合子）。

BS4

家系成员中缺乏共分离

人工§5.17
⚡ 怎么用 · 速判
  1. 触发：患者家系中出现变异与表型不共分离。
  2. 先排除三类情况：① 基因型(+)表型(−)者的轻度症状、不完全外显、表型多变、年龄/性别依赖外显率 ② 基因型(−)表型(+)的拟表型 ③ 生物学家庭关系（收养、非生父、配子捐赠等）。
  3. 三者均可排除后才可使用 BS4。
输出：BS4（Strong）。
5.17.1 ACMG-2015 Guideline

在一个家系成员中缺乏共分离。注：这部分需要考虑复杂疾病和外显率问题[1]。

5.17.2 解读规则

当患者家系中出现了变异与表型不共分离的情况，需先排除以下几种情况：

  1. 针对基因型(+)表型(−)，需进行仔细的临床评估来排除正常个体的轻度症状，需考虑疾病不完全外显、表型多变、和年龄/性别依赖性的外显率；
  2. 针对基因型(−)表型(+)，需考虑可能的拟表型（患者表型由非遗传或不同的遗传原因引起）；
  3. 需确认生物学家庭关系，排除收养、非生父、精子和卵子捐赠以及其他非生物学关系。
BP2

与已知致病变异共存（顺式 / 反式）

人工§5.18
⚡ 怎么用 · 速判
  1. 判定：显性遗传病中在另一条染色体同一基因存在已知致病变异；或任意遗传模式下同一条染色体同一基因存在已知致病变异。
  2. ⚠️：BP2 一旦加分，无需继续判断其他人工证据项；该项很少使用，需谨慎分析。
输出：BP2（Supporting）。
5.18.1 ACMG-2015 Guideline

在显性遗传病中又发现了另一条染色体上同一基因的一个已知致病变异，或者是任意遗传模式遗传病中又发现了同一条染色体上同一基因的一个已知致病变异[1]。

5.18.2 注意事项
若 BP2 已加分，则无需继续判断其他人工证据项。BP2 很少用到，使用前需谨慎分析。
BP5

病例已存在另一分子致病原因

人工§5.19
⚡ 怎么用 · 速判
  1. 前提：病例已有另一明确分子病因（AR 疾病的 P/LP 复合杂合或纯合），且待评变异为纯合 / 复合杂合（杂合不适用）。
  2. 三步：① 待评变异无独立表型相关 case、无有害功能实验 ② 变异 A 与 B 分别独立评估且均为 P/LP（其一为 VUS 则不适用；若无独立 case 也不适用）③ 充分排除多基因遗传模式与表型严重程度受基因修饰影响。
输出：BP5（Supporting）。
5.19.1 ACMG-2015 Guideline

在已经有另一分子致病原因的病例中发现的变异[1]。

5.19.2 解读规则

5.19.2.1 患者症状为已明确遗传病因（如变异 A/A、A/B）的 AR 疾病，同时还检出另一基因上的待解读变异：若待解读变异为杂合，则不适用BP5；若为纯合或复合杂合，进行如下判定：

  1. 待解读变异是否有单独出现的表型相关的 case 或功能实验。若存在独立 case 或功能实验证明有害，则不适用 BP5；若不存在，进行下一步。
  2. 分别独立核查变异 A 和变异 B 的致病性。若检索到的文献中变异 A 和/或 B 总是与目标解读变异一同出现（即无变异 A 和/或 B 的独立 case），则不适用 BP5。若其他表型相关 case 中单独检出过变异 A 和/或 B，则对其分别进行独立评估判断致病性；若 A 和/或 B 为 VUS 变异，则不适用 BP5；若 A 和 B 均为 P/LP，进行下一步。
  3. 在充分排除疾病多基因遗传模式、当前患者的表型严重程度受影响（考虑基因修饰）后，则适用 BP5。
