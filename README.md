# Variant Atlas｜遗传解读训练

面向 WES/WGS 单基因病诊断的中文遗传变异解读学习平台。从分子遗传学基础、质量控制和 HGVS 规范开始，逐步训练 ACMG/AMP 证据赋分、病例级整合、报告写作和高风险边界判断。

在线学习：[variant-atlas-genetics.jevettewquapbd.chatgpt.site](https://variant-atlas-genetics.jevettewquapbd.chatgpt.site)

## 主要功能

- 24 节核心课程与 28 节 WGS 专项课程，其中 12 节锚点课扩展为长课工作坊
- ACMG/AMP 28 条证据规则工作手册及 ClinGen 通用细化提示
- 证据组合练习、专项赋分练习、核心三级测验与 WGS 三级测验
- 8 个核心病例、18 个 WGS 高风险情境和 6 个长流程旗舰病例
- WES/WGS、单人/家系共 21 类报告情境，按完整性、病例逻辑、安全边界、可追溯性和行动性评分
- SOP 化的 10 步变异底稿、12 步 WES 病例流程和 15 步 WGS 病例流程
- 规范版本中心记录适用范围、版本、复核日期和高风险边界
- 统一学习档案汇总课程、病例、测验、工作流和报告进度，支持 JSON 导入导出
- 学习进度保存在访问者自己的浏览器中，不需要账户或 ChatGPT 登录

## 内容原则

平台以 ACMG/AMP 框架、ClinGen Variant Classification Working Group 通用建议和 VCEP 疾病特异规范为核心。SVI Working Group 作为历史文件署名保留，不再用作当前工作组名称。病例中的公开证据、指南附例和教学重组信息会分别标注，不把教学重组患者当作新的病例证据。

SOP 相关内容经过通用化重组，不包含企业文控信息、内部职责、原始表格、机构专属阈值或患者资料。真实工作中应依次核查：

1. 当前有效的疾病/基因特异规范；
2. ClinGen 通用建议；
3. ACMG/AMP 基础框架；
4. 所在实验室经批准的现行 SOP。

## 医学与隐私边界

- 本项目仅用于学习，不替代临床诊断、实验室复核或职业资质认证。
- 不要在网站、Issue、Discussion 或代码提交中录入真实患者信息。
- VUS 不应单独用于确诊、无症状亲属预测或不可逆临床决策。
- 数据库、指南和专家规范会更新，真实解读必须重新核查当前版本。

## 本地运行

要求 Node.js `>=22.13.0`。

```bash
npm ci
npm run dev
```

生产构建与回归测试：

```bash
npm run build
node --test tests/rendered-html.test.mjs
```

## 技术结构

- React 19
- Vinext / Vite
- Cloudflare Worker 兼容构建
- 浏览器 `localStorage` 保存个人学习进度
- 版本化学习档案可在不同设备间手动导入导出
- 不依赖用户账户、患者数据库或服务端学习档案
