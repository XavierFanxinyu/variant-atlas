# Variant Atlas｜遗传解读训练

面向 WES/WGS 单基因病诊断的中文遗传变异解读学习平台。从分子遗传学基础、质量控制和 HGVS 规范开始，逐步训练 ACMG/AMP 证据赋分、病例级整合、报告写作和高风险边界判断。

在线学习：[variant-atlas-genetics.jevettewquapbd.chatgpt.site](https://variant-atlas-genetics.jevettewquapbd.chatgpt.site)

## 主要功能

- 24 节核心课程与 28 节 WGS 专项课程，其中 12 节锚点课提供可保存文字底稿的决策工作坊
- ACMG/AMP 28 条证据规则工作手册及 ClinGen 通用细化提示
- 证据组合练习、专项赋分练习、核心三级测验与 WGS 三级测验
- 8 个核心病例、18 个 WGS 高风险情境和 6 个逐阶段填写分析、揭示参考、支持重做的旗舰教学情境（不是6份完整原始患者病例）
- WES/WGS、单人/家系共 21 类报告情境，按完整性、病例逻辑、安全边界、可追溯性和行动性评分
- SOP 化的 10 步变异底稿、12 步 WES 病例流程和 15 步 WGS 病例流程
- 规范版本中心记录适用范围、版本、复核日期和高风险边界
- 统一学习档案汇总课程、病例、测验、工作流和报告进度，支持 v4 JSON 备份、旧版兼容、导入预览、覆盖确认与失败回滚
- 学习进度保存在访问者自己的浏览器中，不需要账户或 ChatGPT 登录

## 内容原则

平台以 ACMG/AMP 框架、ClinGen Variant Classification Working Group 通用建议和 VCEP 疾病特异规范为核心。SVI Working Group 作为历史文件署名保留，不再用作当前工作组名称。病例中的公开证据、指南附例和教学重组信息会分别标注，不把教学重组患者当作新的病例证据。

SOP 相关内容经过通用化重组，不包含企业文控信息、内部职责、原始表格、机构专属阈值或患者资料。真实工作中应依次核查：

1. 当前有效的疾病/基因特异规范；
2. ClinGen 通用建议；
3. ACMG/AMP 基础框架；
4. 所在实验室经批准的现行 SOP。

## 医学与隐私边界

- 本项目仅用于学习，不替代临床诊断、实验室复核或职业资质认证。
- 不要在网站、Issue、Discussion 或代码提交中录入真实患者信息。
- VUS 不应单独用于确诊、无症状亲属预测或不可逆临床决策。
- 数据库、指南和专家规范会更新，真实解读必须重新核查当前版本。

## 本轮迭代（v1.6.0）

“证据规则”新增PS2/PM6逐观察计分、PP1/PP4联合训练及PVS1逐步决策树；保留PM3。分别展示原始贡献、类别封顶、同等位基因分配、规则版本和停止关口。新发观察分与贝叶斯分严格分开，特异规则/复杂家系不强行输出通用结论。

“人工审核”新增3份公开证据包、7条待审输出：NIPBL/PAH指南附例与已发表GAA变异试评。候选软件输出是明确标注的教学设置，不补造病例事实；逐条选择接受/修改/暂缓/不适用、记录强度和理由，再揭示参考审核。原十道基础练习保留。

新草稿、路径与提交进入本地档案v6，兼容v1–v5备份；审核错误进入统一复习队列，不改变既有认证门槛。适用范围及原始来源见 [v1.6来源审计](sources/ITERATION-1.6.md)。

## 前轮迭代（v1.5.0）

进入“人工审核”学习自动化辅助结果的六个复核关口和十道逐步揭示练习；进入“证据规则”查看28条强度调整说明及PM3逐例计算器。数值有原始建议、版本与适用范围，没有通用阈值的代码明确转向VCEP。本站不接入临床自动解读引擎，不自动签发报告。

新练习、审核理由与PM3草稿纳入本地学习档案v5，兼容旧档案。错题进入统一复习队列；理由长度检查不等于医学语义评分，参考判断不等于职业资质。PM3实验室与原2015组合台分开，病例观察分不能直接当作贝叶斯分。

原组合台补齐ClinGen PM2建议的“极强＋支持→可能致病”扩展，并明确标记来源；按钮显示本台实际固定强度。本轮来源、范围与安全设计见 [v1.5来源审计](sources/ITERATION-1.5.md)。

## 上轮迭代（v1.4.0）

修复进度恢复、WGS重做、筛选空结果、过早计分与工作流重复计数；统一综合训练门槛，保留各训练最高分。报告检查区分不同变异通道，并提示其仅为规则式辅助评估，不能证明医学判断正确。

档案导入将**替换全部当前记录**，不是合并；确认前请导出备份。不同窗口同时编辑同一份草稿时会阻止覆盖并提示重新加载。清除和导入会让所有模块重新载入，避免旧界面把已清除的进度写回来。

新增统一复习队列，汇总核心/WGS测验、证据练习、WGS与旗舰题目和报告风险；支持不改动原始成绩的再练习，24小时后重新进入复习。报告实验室提供逐项命中文本及未满足要求的说明。

本地验证：28项测试（21项功能行为、7项已有渲染/结构回归）、学习应用类型检查、代码检查、生产构建。没有进行浏览器点击回归。原有开发运行器的 Windows `workerd` 启动遇到 `EFTYPE`，生产预览可启动并返回200；未更换运行器版本或绕过权限。学习应用类型检查不覆盖模板遗留的 Worker/D1 类型缺失。

后续优先级及已核对的来源范围见 [v1.4迭代记录](sources/ITERATION-1.4.md)。

- React 19
