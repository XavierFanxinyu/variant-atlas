## 本轮处理的实际缺口

| 问题 | 处理 | 验证范围 |
| --- | --- | --- |
| 挂载时默认数据早于恢复数据写入 | 统一先恢复后保存；异常时保留原记录并提示 | 持久化会话单元检查、代码审查 |
| 清除后旧界面可重新写回旧进度 | 重建界面、存储代次校验 | 清除后旧会话拒绝写入测试 |
| 导入校验弱，写入一半失败 | 已知模块、字段及选项范围校验，确认替换，回滚 | 旧版兼容、异常数据、失败回滚、往返测试 |
| WGS练习重做无效、答案未保存、空结果仍显示其他病例 | 保存答案和位置，清空本轮答案但保留最高分，空结果提示 | 代码审查、计分函数测试 |
| 工作流同一WGS关口被计两次 | 跨入口取并集，分母37 | 全关口去重测试 |
| 旗舰任务和答案一起隐藏，点下一步不需思考 | 任务先显示，文字底稿，参考揭示后前进 | 代码审查、构建 |
| 报告正确否定句被误报，所有通道要求转录本 | 分句和局部否定检查；按情境检查记录格式 | 安全表达与六类情境格式测试 |

认证均为可本地修改的形成性训练记录，不是防作弊考试，更不是医学资格。课程“完成”仍由学习者自评；新增文字底稿不会自动证明判断正确。

## 本轮来源核对边界

只对下列入口及相关主题进行了定向核对，不代表全部指南截至本日均已完成系统性更新。

- [ACMG NGS 2021，PMID 33927380](https://pubmed.ncbi.nlm.nih.gov/33927380/)：对应检测设计、验证与报告的技术标准。
- [ACMG生殖系SV技术考虑，PMID 36507974](https://pubmed.ncbi.nlm.nih.gov/36507974/)：在线2022-12-12、期刊2023年2月；修正原来的3月记录。
- [ACMG DM1检测2024修订，PMID 38836869](https://pubmed.ncbi.nlm.nih.gov/38836869/)：核对DMPK/CTG专项标准身份。
- [mtDNA分类规格，PMID 32906214](https://pubmed.ncbi.nlm.nih.gov/32906214/)：期刊2020年12月；其用途是线粒体特异的分类语境，不能简化为血液异质性数值判病。
- [ClinGen剪接建议，PMID 37352859](https://pubmed.ncbi.nlm.nih.gov/37352859/)与[官方2024-03-22答疑](https://www.clinicalgenome.org/docs/clingen-svi-splicing-subgroup-response-to-feedback/)：补充到CFTR教学情境，用于追溯RNA证据路由，不作为该情境虚拟患者数据的出处。
- [GeneReviews Prader-Willi Syndrome](https://www.ncbi.nlm.nih.gov/books/NBK1330/)：核对甲基化、亲本来源与机制鉴别的入口。不能把ROH观察直接写成PWS确诊。

## 下一轮优先级

1. **完整真实病例档案优先于继续增加情境数量。** 首批选择有开放原始证据的WES阴性升级、结构事件、印记/mtDNA病例。每例固定 DOI/PMID、患者编号、表/图/补充材料定位、GRCh38或原组装、时间截点、实际已做/未做检查；来源不提供的值明确留空。不用教学补充的数据满足证据计数。
2. **逐项证据与报告审计。** 每条代码需要底层观察、适用性、强度、反证、依赖关系、原文定位和版本；本轮报告评分已展示情境/边界/格式检查的命中文本与未满足项；后续应支持更细的“不适用”理由和人工复核流程。关键词分数不能称为临床正确率。
3. **课程掌握度与迁移题。** 本轮已把WGS/旗舰/报告风险纳入统一队列，复习状态24小时后过期；这只是学习安排，不是医学指南要求。后续仍需将课程自评与独立迁移题通过分开，不能把记住原题等同于掌握。
4. **完整浏览器回归后再发布。** 逐项验证恢复/导入/清除、同设备多窗口冲突、筛选后刷新、旗舰六阶段、报告通道、键盘可达性与窄屏溢出。浏览器访问失败和隐私模式下的提示也要检查。

- 未进行浏览器点击/截图测试；不能据自动测试宣称所有界面行为均已验证。
- 全项目旧类型配置仍缺少Worker/D1环境类型；新增类型检查明确限定学习应用。应在后续环境维护中使用正式运行时类型补齐。
